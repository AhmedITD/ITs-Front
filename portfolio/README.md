# Svelte Personal Portfolio

This is a minimal Svelte portfolio starter created for you.

Quick start

1. Install dependencies:

```bash
cd portfolio
npm install
```

2. Run development server:

```bash
npm run dev
```

Open http://localhost:5173 (Vite default) in your browser.

Notes

- This project follows the Svelte Getting Started guide: https://svelte.dev/docs/svelte/getting-started
- Replace the placeholder content in `src/components` and `src/App.svelte` with your own text and links.
